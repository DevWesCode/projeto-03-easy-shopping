# 📱 Easy Shopping Via Mobile

Este é o **terceiro projeto** desenvolvido com **HTML e CSS**, com o objetivo de consolidar os conhecimentos adquiridos sobre estruturação de páginas, estilização, responsividade e boas práticas de layout.


## ✅ Objetivo

Criar uma página com layout moderno e responsivo que apresenta uma proposta de compras online via dispositivo móvel. A estrutura foi pensada para ser limpa, intuitiva e adaptável a diferentes tamanhos de tela.


## 🛠️ Tecnologias Utilizadas

- **HTML5**
- **CSS3**


## 📌 Funcionalidades

- Layout dividido em duas seções: conteúdo informativo e área visual com navegação.
- Menu de navegação com links estilizados.
- Design responsivo adaptado para dispositivos móveis.
- Animações e interações em botões e links com pseudo-classes CSS.


## 🧠 Aprendizados

Durante o desenvolvimento deste projeto, foram praticados conceitos como:

- Estruturação semântica com HTML;
- Uso de `display: inline-block` para layout lado a lado;
- Implementação de responsividade com `@media screen`;
- Estilização com sombras, bordas arredondadas e efeitos de transição;
- Organização e boas práticas com CSS.
